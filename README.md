# Spring Basic Article API with several tests

Este projeto em Java 17 utiliza de diversos testes, como Testes Unitários, Performance e Serviços Web, para avaliar a qualidade de um software.

## Run

Para compilar o código e rodar o código, utilize os comandos:

```bash
mvnw clean package
mvnw spring-boot:run
```

## Tests

Testes unitários com JUnit:

```
spring-basic-article-api/src/test/java/com/example/api/article
```

---

Para testes de performance, abrir o ambiente JMeter com o arquivo .jmx fornecido em:

```
spring-basic-article-api/jmeter
```

Download JMeter: 🔗https://github.com/apache/jmeter/releases

---

Para testes de serviços web, abrir a Collection do Bruno fornecida em:

```
spring-basic-article-api/bruno
```

Download Bruno: 🔗https://github.com/usebruno/bruno/releases
